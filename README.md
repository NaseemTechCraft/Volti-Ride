# Volti Ride

## Overview

Volti Ride is a responsive static front-end website showcasing a modern ride-booking interface. It demonstrates a clean landing page, vehicle options, and a simple booking form aimed at providing users a quick way to request rides and explore service features.

## Features

- Responsive landing page
- Vehicle options and service information
- Simple booking form (HTML/CSS/JS)
- Custom web fonts and icon-ready layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts (Nunito Sans, Quicksand)

## Installation

1. Clone the repository.
2. Navigate to the project directory.
3. No dependencies required for the static site.
4. Open `Index.html` in a web browser.

## Usage

Open `Index.html` in your browser. Navigate the landing page to view service sections, choose vehicle options, and use the booking form to simulate a ride request. The page is fully responsive for mobile and desktop.
